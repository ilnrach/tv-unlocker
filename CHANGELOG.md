# Changelog

## 4.3

- Первый публичный релиз.
- Нейтральные тексты уведомлений, IP приёмника вынесен в константы
  (`PC_PRIMARY`, `PC_UPLOAD_HOST`).

## 4.2

- `[T] ТЮНИНГ`: переключение режима картинки VIVID → STANDARD через
  `ITvApiPictureControl`, отключение шумодава (NR), DLC, Surround, Dbx,
  включение AVL — с верификацией через get-методы.

## 4.1

- Рефакторинг обхода под-API, логирование сигнатур методов.

## 4.0

- `[G] РАБОЧАЯ РАЗБЛОЖИКА`: `SystemProperties.set` от system-uid
  (`service.adb.tcp.port=5555`, `ctl.start adbd`) — рабочий путь включения ADB
  на CVTE TP.MT9256; батарея `eventSystemSendKeyEvent` для сервисных кодов.

## 3.x

- Подключение к `ITvApiManager` (bind по action, загрузка интерфейса
  из `/system/framework/cvte.media.jar`), диагностическая батарея bind'ов
  и командных интентов, чтение `/vendor/tvconfig`, инжекция клавиш,
  рекон манифестов и dex вендорских APK.

## 2.x

- Пробивка: прямые записи настроек, broadcast по словарю action, старт
  сервисов, чтение провайдеров; выгрузка отчётов на флешку и POST на ПК;
  рекон прошивки.

## 1.x

- Первый сканер скрытых активностей, отчёт о платформе.
